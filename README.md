# Gift exchange draw

One web page. No server, no accounts, no tracking. Built so a helper does the setup and a not-so-techy organizer only has to tap big buttons.

## 1. Put it online (helper, about 5 minutes)

The page has to be online so the links open on everyone's phone.

GitHub Pages:

1. Create a new public repo on GitHub, for example `gift-exchange`.
2. Upload `index.html` to it.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. After a minute the page is at `https://<your-username>.github.io/gift-exchange/`.

Netlify Drop also works: drag this folder onto https://app.netlify.com/drop.

The website only hands out the page. Everything private travels inside the links, after the `#`, and browsers never send that part to the website.

## 2. Set it up (helper)

Open the online page and fill in:

- The exchange name, spending limit and gift day
- The organizer's name, plus your own name and phone so they can text you for help
- Everyone in the exchange. Phone numbers are optional but worth it: the organizer's Text button then opens a message already addressed to each person.
- Couples to keep apart
- Last year's results file or backup link, if you have one, so nobody gets the same person again

Tap **Send to [organizer]** and text them the message.

## 3. What the organizer does

1. Tap the link, check the names, tap **Everything looks right. Draw names!**
2. Work through three jobs, one screen at a time:
   - **Send the family link** to the family group text (safe for everyone to see)
   - **Send everyone their secret code**, one private text each, with a big Text button per person
   - **Save a backup** by texting it to themselves or the helper
3. Done. If someone loses a code or can't open the link, **Need help?** on the same page covers it.

If the organizer taps the setup link again later, it goes straight back to their jobs. It doesn't redo the draw.

## 4. What everyone else does

Tap the family link, tap their name, type the code they were texted, then tap to see who they got. Their phone remembers them after that. They can also make a wishlist and post it in the group text. Only the person who drew them can open it.

## Why codes go one-on-one

The family link holds everyone's result, each one locked. A code unlocks one person's result. If codes went in the group text, anyone could open anyone's.

## Good to know

- The organizer can see everything if they choose to look (it's tucked under Need help). Their phone doesn't show it unless they ask.
- The backup link and the results file show who has who. Keep them out of the family chat.
- If the organizer draws again, everyone needs the new family link and new codes.
- Some chat apps open links in their own built-in browser with separate memory. If a wishlist says "locked", open the family link in that same app and type the code again first.
- Codes look like `MAPLE-COMET-482` (about 15 million possibilities, deliberately slow to guess). Enough to stop a curious sibling, not a determined hacker.
